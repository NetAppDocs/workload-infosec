:hardbreaks:
:nofooter:
:icons: font
:linkattrs:

The following metrics are for operational logs and events:

* Volume-level CloudWatch metrics (collected per volume)
* File system-level CloudWatch metrics (collected per file system)
* Computed metrics
* Collection schedule and retention

== Other notes about metrics

* Computed metrics use this formula:
** Throughput (Bytes/Second) = (NetworkSentBytes + NetworkReceivedBytes) / period
* Volume and cluster metrics are refreshed every 12 hours.
* Latency metrics are refreshed every 20 minutes.
* DynamoDB items auto-expire after 14 days.

== Telemetry

Some notes about telemetry data collection:

* OpenTelemetry traces exported via OTLP HTTP to SigNoz (internal observability)
* AI usage metering (token counts, model costs) stored in AWS Timestream
* NetApp Console audit records (action name, status, request/response metadata, timestamps)
