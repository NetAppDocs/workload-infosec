= Considerations for Workload Factory credentials
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
This guidance compares credential handling patterns that preserve least privilege and reduce exposure of ONTAP administrative secrets.

== Read-only ONTAP access model

For AI-powered features (event analysis and latency diagnostics), Workload Factory uses read-only ONTAP credentials when available. This ensures the AI agent cannot make modifications to your storage environment; it can only observe and diagnose.

== Credential storage options comparison

[cols="2,2,3,2,2,2",options="header"]
|===
|Option |AWS credentials |ONTAP credentials |What's stored |Encryption |Secrets Manager option

|Workload Factory managed
|IAM role ARN + external ID
|Password (encrypted)
|IAM role ARN + external ID; ONTAP admin password (encrypted)
|Role ARN is not a secret (stored as-is); ONTAP password uses AES-256 envelope encryption
|No

|AWS Secrets Manager
|IAM role ARN + external ID
|Secrets Manager ARN reference
|IAM role ARN + external ID; Secrets Manager ARN
|Role ARN is not a secret (stored as-is); Secrets Manager encrypts the secret in your account
|Yes (password stays in your account)
|===

[cols="2,4",options="header"]
|===
|Item |Details

|GovCloud requirement
|Standard IAM role; ONTAP credentials must use Secrets Manager (password storage not permitted)

|Rotation
|Role policies are updated in your account. Update the ONTAP password in Workload Factory (managed option) or rotate it in AWS Secrets Manager.
|===
