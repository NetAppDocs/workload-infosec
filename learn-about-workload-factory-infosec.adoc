Information security is a core part of NetApp Workload Factory design and operation. This guide helps Information Security, Cloud Platform, and Storage teams evaluate and onboard Workload Factory in a way that supports enterprise security requirements.

== What Workload Factory does

Workload Factory is a SaaS life-cycle management platform designed to help you optimize and manage workloads (for example, storage, VMware migrations, EDA projects, and database environments) using Amazon FSx for NetApp ONTAP Your workloads run in AWS, and Workload Factory interacts with AWS and (when required) ONTAP management endpoints through well-defined credential and connectivity paths.

== Core security principles used in this guide

Confidentiality::
Protect data from unauthorized access through identity controls, least privilege, encryption, and network boundaries.

Integrity::
Protect systems and configurations from unauthorized or unintended change using permission scoping, change control, and auditability.

Availability::
Ensure authorized users can access the service and workloads through resilient AWS designs and operational monitoring.

== Get started quickly
* Start with _view, planning, and analysis_ (read-only) permissions and expand only as required.
* Use AWS CloudTrail to validate `sts:AssumeRole` activity for the integration role.
* Decide upfront whether you need ONTAP-native operations (which may require deploying Lambda link or NetApp Console agent).
* Decide upfront whether generative AI is permitted and whether residency constraints require single-region inference profiles.

== Compliance and security posture for NetApp Workload Factory

Compliance and security for NetApp Workload Factory are a top priority for NetApp. All workloads in Workload Factory run on Amazon FSx for NetApp ONTAP. In addition to link:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/security.html[AWS security features^], NetApp Workload Factory has link:https://trust.netapp.com/[SOC2 Type 1, SOC2 Type 2, and HIPAA compliance^]. 

Amazon FSx for NetApp ONTAP for NetApp Workload Factory is an link:https://aws.amazon.com/solutions/guidance/deploying-enterprise-apps-with-netapp-bluexp-workload-factory-for-aws-and-amazon-fsx-for-netapp-ontap/[AWS solution for deploying enterprise apps^] created with Well-Architected best practices in mind.
