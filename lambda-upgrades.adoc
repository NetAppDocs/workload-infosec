= Lambda link upgrades and lifecycle in NetApp Workload Factory
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Lambda link lifecycle controls cover deployment, health monitoring, and controlled image updates with minimal operational exposure.

Workload Factory can update the Lambda link container image to deploy improvements or security patches without requiring you to redeploy the CloudFormation stack. This uses the `lambda:UpdateFunctionCode` permission.

== Lifecycle control points

* *Deployment*: Automated via CloudFormation (or Terraform) stack deployment
* *Monitoring*: Health checks detect connectivity issues; failure counters track reliability
* *Removal*: You delete the CloudFormation stack from your AWS account to remove the Lambda and associated resources
