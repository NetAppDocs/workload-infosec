= AI tool boundaries for NetApp Workload Factory
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Amazon Bedrock uses the AWS CLI and ONTAP CLI diagnostic tools in a read-only manner. These tools allow the AI features to inspect supported AWS and ONTAP environments to help diagnose issues without changing the resources they examine. The tools block mutating commands and limit output by size and execution. Data is only used transiently for diagnostic purposes and is not retained by NetApp Workload Factory or AWS.

== Tool safety controls

[cols="2,3,4",options="header"]
|===
|Tool |Capability |Safety controls
|AWS CLI (read-only) |Execute read-only AWS CLI commands (describe, list, get) |Blocks all mutating verbs (create, delete, modify, update, put, remove). Maximum 10 commands per step. Output truncated at 20 KB.
|ONTAP CLI (read-only) |Execute read-only ONTAP CLI commands using SSH |Blocks all mutating verbs (delete, destroy, create, modify, move). Output truncated.
|===

The agent cannot modify, create, or delete resources. It can only observe and diagnose.

== Data retention and model training boundaries

Per AWS policy, Amazon Bedrock does not store or use your inputs and outputs to train or improve foundation models.
For on-demand inference (used by Workload Factory), AWS processes your data transiently and does not retain it after returning the response.
