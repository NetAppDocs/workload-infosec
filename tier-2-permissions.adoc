= Tier 2 Workload Factory operations and remediation permissions
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
The operations and remediation permissions are optional and enabled by default. Tier 2 permissions enable volume lifecycle, backup management, S3 access points, metadata catalog, and AI-powered event analysis.

Resource scope: All resources (`*`), except CloudTrail actions which are conditioned on the tag `netapp-fsx-s3-metadata=journal`.

NOTE: AI inference runs in your AWS account using your Bedrock inference profiles. No data is sent outside your account for AI features. 

[cols="2,4,3",options="header"]
|===
|Permission |Purpose |Impact if removed

|fsx:CreateVolume
|Create new volumes
|Volume creation unavailable

|fsx:DeleteVolume
|Delete volumes
|Volume deletion unavailable

|fsx:UpdateFileSystem
|Modify throughput and storage capacity
|File system updates and auto-capacity management disabled

|fsx:UpdateStorageVirtualMachine
|Modify SVM settings
|SVM configuration changes unavailable

|fsx:UpdateVolume
|Modify volume size, tiering, and QoS
|Volume modifications unavailable

|fsx:CreateBackup
|Create on-demand backups
|Manual backup creation unavailable

|fsx:CreateVolumeFromBackup
|Restore a volume from backup
|Restore from backup unavailable

|fsx:DeleteBackup
|Remove backups
|Backup deletion unavailable

|fsx:TagResource / fsx:UntagResource
|Manage FSx resource tags
|Tagging operations fail

|fsx:CreateAndAttachS3AccessPoint
|Create an S3 access point on a volume
|S3 access point creation unavailable

|fsx:DetachAndDeleteS3AccessPoint
|Remove an S3 access point from a volume
|S3 access point removal unavailable

|s3:CreateAccessPoint / s3:DeleteAccessPoint
|S3 access point lifecycle
|S3 access point operations fail

|s3:TagResource / s3:UntagResource / s3:ListTagsForResource
|S3 resource tagging
|S3 tag operations fail

|s3:GetObjectTagging / s3:ListBucket
|Query metadata catalog content
|Metadata catalog queries degraded

|bedrock:InvokeModel / bedrock:InvokeModelWithResponseStream
|AI-powered event analysis and diagnostics
|AI analysis features unavailable

|bedrock:ListInferenceProfiles / bedrock:GetInferenceProfile
|Enumerate available AI models
|Cannot configure AI features

|s3tables:CreateTableBucket / s3tables:CreateTable / s3tables:CreateNamespace
|Create metadata catalog structures
|Metadata catalog creation fails

|s3tables:GetTable / s3tables:GetTableBucket / s3tables:GetNamespace / s3tables:GetTableMetadataLocation
|Read metadata catalog configuration
|Metadata catalog reads fail

|s3tables:PutTableData / s3tables:GetTableData
|Write and read metadata catalog entries
|Metadata catalog operations fail

|s3tables:ListTables / s3tables:ListNamespaces / s3tables:ListTableBuckets
|Enumerate metadata catalog objects
|Metadata catalog navigation fails

|s3tables:UpdateTableMetadataLocation
|Update catalog metadata pointers
|Catalog location updates fail

|s3tables:ListTagsForResource / s3tables:TagResource
|Metadata catalog tagging
|Catalog tag operations fail

|cloudtrail:PutEventSelectors / cloudtrail:GetEventSelectors
|Metadata catalog change journaling
|Catalog journaling unavailable
|===
