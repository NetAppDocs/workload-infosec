= Observability overview for NetApp Workload Factory
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]

Observability signals help support operational monitoring, troubleshooting, and investigations. In NetApp Workload Factory, observability includes metrics, telemetry, and operational records.

== Telemetry and operational records (high level)

Workload Factory uses the following telemetry and operational record types:

* OpenTelemetry traces exported via OTLP HTTP to SigNoz (internal observability)
* AI usage metering (token counts, model costs) stored in AWS Timestream
* NetApp Console audit records (action name, status, request/response metadata, timestamps)
