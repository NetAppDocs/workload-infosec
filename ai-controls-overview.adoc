= AI controls overview for NetApp Workload Factory
:toc: macro
:toclevels: 2

toc::[]

Workload Factory includes generative AI features that accelerate diagnosis while enforcing security controls for model access, data scope, and runtime behavior.

AI diagnostics are disabled by default.

== Security-scoped AI feature overview

Workload Factory currently applies generative AI to the following features:

* Ask Me assistant (RAG with curated NetApp documentation, source-backed responses)
* Latency analysis
* EMS event analysis

== AWS Bedrock overview for AI diagnostics

Workload Factory uses Amazon Bedrock for AI inference, with execution in your AWS account and under your configured credentials and inference profile.
