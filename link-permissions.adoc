= Workload Factory link permissions
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Link permissions are optional, though they are required for ONTAP-native operations.

When you deploy a Link in your VPC, its execution role requires the following permissions:

[cols="2,4",options="header"]
|===
|Permission |Purpose

|ec2:CreateNetworkInterface / ec2:DescribeNetworkInterfaces / ec2:DeleteNetworkInterface
|VPC networking for the Lambda function

|ec2:AssignPrivateIpAddresses / ec2:UnassignPrivateIpAddresses
|IP management for VPC attachment

|secretsmanager:GetSecretValue (scoped to `FSxSecret*`)
|Retrieve ONTAP credentials from your Secrets Manager (only when you choose Secrets Manager storage)
|===
