= AWS Bedrock opt-in requirements for NetApp Workload Factory
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
AI features require IAM permissions, an inference profile, and connectivity controls before they can be enabled.

AI features are disabled by default. 

Bedrock inference executes in the AWS region specified by your inference profile. If you use a cross-region inference profile, AWS might route the request to any region in the profile's configuration per standard AWS Bedrock behavior. Data does not leave AWS infrastructure.

.Before you begin
Complete the following security prerequisites before enabling AI features:

* Make sure your account includes an AWS Bedrock inference profile.
* Have a connected Lambda link with SSH capability for diagnostic data collection.

.Steps

. Grant Bedrock permissions in your IAM role:
+
`bedrock:InvokeModel, bedrock:InvokeModelWithResponseStream, bedrock:ListInferenceProfiles, bedrock:GetInferenceProfile`
. Configure the inference profile ARN in Workload Factory settings.
+
If any prerequisite is missing, the system reports the specific missing component and AI features remain inactive.
. Optionally, you can disable AI features. 
+
Remove the Bedrock permissions from your IAM role, or delete the Bedrock configuration in Workload Factory settings. AI features immediately become unavailable with no residual data processing.
