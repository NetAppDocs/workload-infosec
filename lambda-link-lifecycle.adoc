= Lambda link lifecycle for NetApp Workload Factory
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]

Lambda link lifecycle controls cover deployment, health monitoring, and controlled image updates with minimal operational exposure.

Workload Factory can update the Lambda link container image to deploy improvements or security patches without requiring you to redeploy the CloudFormation stack.
This uses the `lambda:UpdateFunctionCode` permission.

== Lifecycle control points

* Deployment: automated via CloudFormation (or Terraform) stack deployment
* Monitoring: health checks detect connectivity issues; failure counters track reliability
* Removal: delete the CloudFormation stack from your AWS account to remove the Lambda and associated resources
