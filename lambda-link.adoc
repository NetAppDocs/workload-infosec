= Learn about using Lambda link with Workload Factory
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Link is an AWS Lambda function deployed in your VPC that keeps ONTAP-native operations inside your AWS account boundary when those operations are not exposed by the AWS FSx API.

For the full cross-system connectivity map, Refer to link:connections.html[Workload Factory connections^].


== Link security architecture

[cols="1,3",options="header"]
|===
|Property |Detail

|Compute
|AWS Lambda (container image)

|Runtime
|Node.js 22

|Deployment
|CloudFormation stack in your AWS account

|VPC placement
|Your subnets, your security groups

|Timeout
|10 seconds per invocation

|Invocation
|Synchronous (`RequestResponse`)

|Package type
|Container image (from NetApp ECR)
|===

== Lambda link versus console agent

The Lambda link and the Connector console agent serve different purposes and have different security and operational implications. The following table compares the tools.

[cols="2,3,3",options="header"]
|===
|Dimension |Link (Lambda-based) |Connector (VM/Pods-based)

|Runtime model
|Serverless (AWS Lambda), customer-deployed
|Customer-deployed VM/containers; runs NetApp console service pods

|Primary scope
|Control-plane ONTAP REST operations (only when AWS APIs do not support the operation)
|Orchestration plus support for data services

|Data services support
|Does not host data services
|Can host data services (runs NetApp console service pods)

|Operational overhead
|No always-on VM
|VM lifecycle management and upgrades

|Networking
|Needs connectivity to ONTAP endpoint; might need Workload Factory endpoint connectivity
|Needs connectivity to managed resources and required endpoints

|Credentials
|ONTAP credentials via Secrets Manager or Workload Factory; AWS role ARN stored in Workload Factory
|Depends on deployed services; typically broader operational footprint
|===
