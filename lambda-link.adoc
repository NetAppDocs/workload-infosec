= Learn about using Lambda link with Workload Factory
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Link is an AWS Lambda function deployed in your VPC that enables Workload Factory to communicate with your FSx for ONTAP management endpoint. It's required for ONTAP-native operations that aren't available through the AWS FSx API.

== Link architecture

[cols="1,3",options="header"]
|===
|Property |Detail

|Compute
|AWS Lambda (container image)

|Runtime
|Node.js 22

|Deployment
|CloudFormation stack in your AWS account

|VPC placement
|Your subnets, your security groups

|Timeout
|10 seconds per invocation

|Invocation
|Synchronous (`RequestResponse`)

|Package type
|Container image (from NetApp ECR)
|===
